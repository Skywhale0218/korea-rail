# 대한민국 철도 노선 메이커 V1.0

대한민국 철도 노선 메이커 v1.0이 배포되었습니다!

**사이트:** https://skywhale0218.github.io/korea-rail/

## 주요 패치 사항 (v1.0)
- 미 반영 구간이 존재합니다.
  OSM 측 문제로 인해 아래 구간은 반영되어 있지 않습니다. 추후 업데이트를 통해 반영하겠습니다.
  1. 경의중앙선 지평, 임진강~도라산
  2. 수인분당선 청량리
  3. GTX-A 전구간
 
- 일부 전동차만 이용 가능합니다.
  사용 가능 전동차는 사이트 내부에 안내되어 있으니 참고해주시기 바랍니다.
  추후 업데이트에 반영하겠습니다.
  
## 주요 기능
- 지도 위에 선로 그리기, 역 찍기
- 수도권 실제 노선 불러오기
- 전동차 모델 선택
- 로그인 후 여러 명이 함께 편집
- 오프라인에서도 제작 가능


## 직접 실행하기
​```bash
npm install
npm run dev
​```
